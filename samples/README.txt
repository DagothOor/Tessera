Sample textures / Образцы текстур

Rock064, Bricks105, PavingStones151, WoodFloor051, Metal063 — base colour maps
(1K JPG) from ambientCG (https://ambientcg.com), CC0 1.0 Universal (public
domain). Taken from the repository https://github.com/amazingsammed/mini_textures
(commit b080ca4), which bundles them under the same licence.

Texelith opens Rock064 on the first start so the node graph shows something.
Only the base colour is included: making the other maps is Texelith's job.
