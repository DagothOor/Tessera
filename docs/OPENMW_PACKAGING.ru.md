# Как собрать мод с картами для OpenMW

English version: [OPENMW_PACKAGING.md](OPENMW_PACKAGING.md).

## 1. Какие файлы нужны

OpenMW находит дополнительные карты по окончанию имени файла: карта лежит рядом с диффузом и называется так же, только с окончанием.

| Файл | Что внутри | Узел Texelith |
|---|---|---|
| `tx_name.dds` | диффуз (заменяет игровой) | «Выход», имя «diffuse» |
| `tx_name_n.dds` | нормаль, формат DirectX (зелёный вниз) | «Выход», имя `_n` |
| `tx_name_nh.dds` | нормаль в RGB, высота для параллакса в альфе | «Параллакс для OpenMW (_nh)» → «Выход», имя `_nh` |
| `tx_name_spec.dds` | RGB — цвет блика, альфа × 255 — показатель блеска | «PBR → OpenMW» → «Выход», имя `_spec` |

На одну текстуру кладите только одну карту нормалей: либо `_n`, либо `_nh`.

В альфе `_nh` значение 128 значит «без сдвига». Весь размах параллакса — 4 % от одного повтора текстуры. Поэтому глубина в узле задаётся в сантиметрах: узел сам переводит её в альфу.

## 2. Как разложить по папкам

```
МойПак/
  Textures/
    tx_name.dds
    tx_name_nh.dds
    tx_name_spec.dds
```

В окне «Пакет…» в поле «Раскладка карт» выберите «всё вместе (рядом с исходником)». В качестве папки вывода укажите `МойПак/Textures`. Раскладки «по папкам вида карты» и «по папке на текстуру» нужны только для просмотра: из них игра карты не найдёт.

## 3. Как подключить в OpenMW

1. Добавьте папку мода в список данных: в лаунчере на вкладке «Data Files» или строкой в `openmw.cfg`:

   ```
   data="D:/mods/МойПак"
   ```

   Чем ниже строка, тем выше приоритет: мод должен идти после папки игры.

2. В `settings.cfg`, раздел `[Shaders]`, включите автопоиск карт — по умолчанию он выключен:

   ```
   [Shaders]
   auto use object normal maps = true
   auto use object specular maps = true
   auto use terrain normal maps = true
   ```

   Без `auto use object specular maps` карты `_spec` у моделей `.nif` не используются.

3. Шаблоны имён (`normal map pattern = _n`, `normal height map pattern = _nh`, `specular map pattern = _spec`) по умолчанию уже такие, как нужно. Менять их не надо.

## 4. Земля (ландшафт)

Карты нормалей для земли работают так же: `_n` или `_nh` и настройка `auto use terrain normal maps`.

Блик у земли устроен иначе. Это отдельный файл `_diffusespec`: RGB — диффуз, альфа — сила блика. Включается настройкой `auto use terrain specular maps`. Готового окончания `_diffusespec` в Texelith пока нет.

## 5. Вариант для шейдера OpenMW-PBR (wareya)

Шейдер wareya читает `_spec` по-другому:

- R — металличность;
- G — шероховатость;
- B — AO;
- A — 1 − SSS.

Обычному OpenMW такой файл не подходит, поэтому Texelith пишет PBR-версии в отдельный набор:

- у узлов «Выход» и «Выход по каналам» задайте набор `pbr`;
- такие файлы попадут в папку рядом с папкой вывода, к имени которой добавлено `_PBR` (например, `МойПак/Textures` → `МойПак/Textures_PBR`).

Удобно выпускать два мода:

```
МойПак/Textures/...          — общий: _nh, _n и всё для обычного OpenMW
МойПак_PBR/Textures/...      — только _spec и диффуз для шейдера PBR
```

В `openmw.cfg` `МойПак_PBR` подключается после `МойПак`. Тогда его `_spec` и диффуз перекрывают обычные, а `_nh` берётся из общего мода. Перенесите `Textures_PBR` в `МойПак_PBR/Textures` вручную.

Установка самого шейдера (по README репозитория wareya):

1. Сделайте копию папки шейдеров OpenMW (`resources/shaders`): именно копию, не переименование.
2. Скопируйте поверх неё шейдеры из репозитория. Ставить поверх другого шейдерного мода нельзя.
3. В `settings.cfg` задайте:

   ```
   force shaders = true
   clamp lighting = false
   force per pixel lighting = true
   ```

4. Версия в основной ветке репозитория — для dev-сборок OpenMW. Для стабильных выпусков берите шейдер со страницы Releases.

## 6. Отражение карты окружения (Morrowind)

Модели с картой окружения (блестящая броня, стекло) отражают её одинаково по всей поверхности. Где и насколько отражать, задаёт карта gloss: её RGB умножает отражение.

- В Texelith это выход «маска отражения (gloss)» узла «PBR → OpenMW»: металл отражает свой цвет, прочее — около 4 %, щели гасятся по AO, шероховатое отражает слабее (настройка «Шероховатость гасит отражение»).
- Запишите её узлом «Выход» с именем `_gloss`.
- По имени файла движок её не находит: в NifSkope у модели в `NiTexturingProperty` назначьте текстуру в слот Gloss. У модели должна быть карта окружения (`NiTextureEffect`), иначе маске нечего умножать.
- OpenMW читает этот слот (`files/shaders/compatibility/objects.frag`: `envEffect *= texture2D(glossMap, …)`). Обычный Morrowind его отключает; включается опцией Morrowind Code Patch.

## 7. MGE XE

Формат карт для PBR-прототипа MGE XE здесь не описан: его документации у нас нет. Обычные `_n`/`_spec` для MGE XE этот документ не покрывает.
